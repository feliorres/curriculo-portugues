Objetivo: substantivo e sua classificação geral

1. O que é substantivo?
Nome das coisas. Ex.: TV, cama, sofá, rua, amor terra.
Substan… → Substância
O que é substância?
Aquilo que algo é.
Para saber se é substantivo:
Aceita ser acompanhado por artigo ou pronome? Ex.: o/a, um/uma, meu/minha)
Se sim, é substantivo.
Exemplo: justiça é substantivo?
A justiça tarda, mas não falha.

2. Substantivos próprios x comuns

2.1 Próprios: significam um único ser específico. Grafados com inicial maiúscula. 
Ex.: Brasil, Miguel, Tietê, Jesus.

2.2 Comuns: significam uma generalização de uma espécie, de um objeto ou um conceito. Grafados com inicial minúscula. 
Ex.: país, garoto, rio, rei.

ipsis litteris = letra por letra, literalmente, exatamente igual


3. Substantivos concretos x abstratos

3.1 Concreto: existe por si mesmo; não depende de outro para ser.
Ex.: Deus, cadeira, vento, água, homem. 

3.2 Abstrato: depende de outro ser para existir.
Ex.: fome, beleza, coragem, saudade.

Revisão
O que é substantivo? Palavra que dá nome às coisas. Palavra que significa substância. Exemplos: cama, cadeira, almofada.
Substantivos próprios x comuns. Próprios: palavras que significam substâncias individuais específicas. Ex.: Maria, Catedral de Notre-Dame. Comuns: palavras que significam conceitos, generalizações, objetos. Ex.: mesa, gato, casa.
Substantivos concretos x abstratos. Concretos: palavras que significam coisas que subsistem por si mesmas. Ex.: árvore, rua, carro. Abstratos: palavras que significam coisas que dependem de outras para existir. Ex.: cor, amor, justiça.

amor, amar, amo, amaria, amador
fala, falo, falar, falaria, falador
Simples: têm somente um radical.

guarda-chuva, girassol, passatempo, couve-flor.

Objetivos
Primitivos e derivados;
Coletivos.

Dica de estudo: Não sabe o significado de uma palavra? Pare – e pergunte, pesquise.


1. Substantivos primitivos e derivados
Significados
Primitivo = Vem primeiro.
Derivado/derivar = Vir de algo; proceder de algo.

Substantivo primitivo
Substantivo que não deriva de outra palavra na nossa língua.
Exemplos:
mar
fumo
pedra
flor

Substantivo derivado
Substantivo que deriva de outra palavra na nossa língua.
Exemplos:
marítimo;
fumar;
pedreiro;
florista.

2. Substantivos coletivos
Coletivo significa conjunto de coisas sob um determinado aspecto.
Substantivos comuns que significam um conjunto de coisas.
O povo brasileiro pensa assim.
Outros exemplos:
alcateia (lobos)
arquipélago (ilhas)
bando (aves, bandidos)
caravana (viajantes, peregrinos)
junta (médicos, bois)
legião (soldados, demônios)

1. Substantivos biformes
Biformes = duas formas, uma para cada gênero (masculino e feminino)
o professor / a professora
o gato / a gata

2. Substantivos uniformes
Uniformes = uma forma para os dois gêneros (masculino e feminino)
Uni = uma + forme = forma
Exemplos:
estudante, criança, pianista, cobra

	2.1 Comuns de dois gêneros
A palavra é a mesma, e a distinção de gênero é feita pelo artigo/adjetivo.
Exemplos: 
o estudante / a estudante;
o cliente / a cliente;
o artista / a artista.

2.2 Sobrecomuns
Substantivos com apenas um gênero gramatical fixo e invariável. O artigo nunca muda.
A criança;
A vítima;
A testemunha;
O indivíduo;
O cônjuge.

	2.3 Epicenos
Substantivos com gênero gramatical fixo referentes a animais.
A cobra macho / A cobra fêmea;
O besouro macho / o besouro fêmea;
A borboleta macho / A borboleta fêmea.

Objetivos

1. Formação do plural
Substantivos podem estar:
No singular: aluno, cão, mesa, povo, manada.
No plural: alunos, cães, mesas, povos, manadas.

2. Regra geral
Substantivos terminados em vogal ou ditongo → Acrescenta-se -s.
Mesas, estantes, pais.
Substantivos terminados em som nasal:
Bem → Bens
Flautim → Flautins

3. Regras especiais
Terminação -ão
1) -ões
balão → balões
botão → botões
casarão → casarões
2) -ães
alemão → alemães
cão → cães
capelão → capelães
3) -s
cidadão → cidadãos
cristão → cristãos
irmão → irmãos

4. Plural com alteração de timbre da vogal tônica
Alguns substantivos no singular são pronunciados com “ô” e, no plural, com “ó”.
olho → olhos
osso → ossos
ovo → ovos
poço → poços
porco → porcos
coro → coros

Alguns, porém, mantêm o “ô”:
acordos, adornos, moços, etc.

Objetivos: substantivo e suas classificações
O que é substantivo;
Substantivos próprios x comuns;
Substantivos concretos x abstratos.

1. O que é substantivo 
Palavra que dá nome.
Palavra que significa substância.
Substan… = substância
O que é substância?
Aquilo que algo é.
Ex.:
Marcelo, caderno, computador, aula, estrela.

Como identificar um substantivo?
Aceita ser acompanhada por artigo ou pronome? (ex.: o/a, um/umas, este/esta, meu/minha).
Exemplo:	
“Meu Deus, que estais pendente em um madeiro”.


2. Substantivos próprios x comuns

Próprios: significam indivíduos específicos. Grafados e letra inicial maiúscula.
Ex.: Brasil, Bryan, Francisco, Tietê, Anchieta, Paraná.

Comuns: significam generalizações, objetos, conceitos. Grafados com inicial minúscula. 
Ex.: país, garoto, rio, avenida, região.

3. Substantivos concretos x abstratos

Concretos → Existem por si independentemente de outro ser.
Ex.: cadeira, vento, Deus, homem, celular.

Abstratos → Dependem da existência de outros.
Ex.: fome, beleza, coragem, corrida.

Aulas 5 e 6

Revisão
O que é substantivo? Palavra que dá nome aos seres, objetos, sentimentos, etc. Ex.: Rafael, parede, Gabriel, computador. Palavra que significa substância. 
Substantivos próprios x comuns. Próprios: substantivos que nomeiam seres individuais específicos: Marcelo, Acutis, Carlo, Alemanha. Comuns: substantivos que significam generalizações, conceitos, objetos. Ex.: homem, escola, menino, país.
Substantivos concretos x abstratos. Concretos: substantivos que significam coisas independentes de outras para existirem. Ex.: concreto (material de construção), homem, pá, casa, garrafa. Abstratos: substantivos que significam coisas que dependem de outraas para existirem. Ex.: paciência, fome, raiva, tristeza, verdade.

1. Simples e compostos

O que é o radical de uma palavra?
Raiz da palavra.
amor, amar, amo, amas, amaria, amador
falar, falo, falas, falaria, falador

Substantivos simples → Têm um só radical.
sol, tempo, chuva, flor
Dante → dantesco 
Substantivos compostos → Têm mais de um radical.
guarda-chuva; girassol; passatempo; couve-flor.


Singular → Substantivo simples tem um só radical.
Plural → Substantivos simples têm um só radical.

Objetivos
Substantivos biformes;
Substantivos uniformes;
Comuns de dois gêneros;
Sobrecomuns;
Epicenos.

1. Substantivos biformes
Biformes = Bi (duas) + formes (formas)
Substantivos com uma forma para o masculino e outra forma para o feminino.
menino/menina;
gato/gata

2. Substantivos uniformes
Uniforme = Uni (uma) + forme (forma)

2.1 Comuns de dois gêneros
Substantivos fixos. A distinção entre masculino e feminino é feita pelo artigo/adjetivo.
O estudante / A estudante;
O cliente / A cliente;
O artista / A artista.


2.2 Sobrecomuns
Substantivos fixos. O artigo nunca muda o gênero da palavra.
A criança;
A vítima;
A testemunha;
O indivíduo;
O cônjuge.

2.3 Epicenos	
Substantivos fixos relativos a animais. A distinção entre macho e fêmea é feita por essas mesmas palavras.
A cobra macho / A cobra fêmea;
O besouro macho / O besouro fêmea;
A borboleta macho / A borboleta fêmea.

Formação do plural dos substantivos

Número = singular e plural
Substantivos podem estar:
No singular: aluno, cão, mesa, povo, manada.
No plural: alunos, cães, mesas, manadas.

1. Regra geral 
Substantivos terminados em vogal ou ditongo → Acrescenta-se -s.
Mesas, estantes, pais
Substantivos terminados em som nasal:
Bem → bens;
Flautim → Flautins


2. Terminação -ão
1) -ões
Balão → Balões
Botão → Botões
Casarão → Casarões
2) -ães
Alemão → Alemães
Cão → Cães
Capelão → Capelães
3) -s
cidadão → cidadãos
cristão → cristãos
irmão → irmãos
mão → mãos

3. Plural com alteração de timbre da vogal tônica
Alguns substantantivos são pronunciados no singular com “ô” e, no plural, “ó”.
olho → olhos
osso → ossos
ovo → ovos
poço → poços
porco → porcos
coro → coros
Alguns substantivos conservam o “ô”.
acordos, adornos, moços.

4. Substantivos terminados em consoante
Mar → Mares
Açúcar → Açúcares
Colher → Colheres

Casos especiais
atlas → atlas
pires → pires
lápis → lápis

5. Terminação -il
Exemplos
Ardil → Ardis
Barril → Barris
Covil → Covis
Casos especiais
Fóssil → Fósseis
Réptil → Répteis
	

Artigos

1. O que são artigos
Palavras que se antepõem aos substantivos para indicar:
que se trata de um ser já conhecido do leitor ou ouvinte → artigo definido.
“Atravessaram o pátio, deixaram na escuridão o chiqueiro e o curral, vazios, de porteiras abertas, o carro de bois que apodrecia, os juazeiros.” (Graciliano Ramos)
que se trata de um simples representante de uma dada espécie ao qual não se fez menção anterior → artigo indefinido.
“Vi que estávamos num velho solar, de certa imponência. Uma fachada de muitas janelas perdia-se na escuridão da noite.” (Branquinho da Fonseca)

Artigos definidos: o, os; a, as. Artigos indefinidos: um, uns; uma, umas.

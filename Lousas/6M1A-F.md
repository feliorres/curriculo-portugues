Objetivo: Substantivo e suas classificações
O que é substantivo;
Substantivos próprios x comuns;
Substantivos concretos x abstratos.

Para que tomar notas no caderno? As notas serem uma extensão da nossa memória.


1. O que é substantivo?
Palavra variável que dá nome aos seres.
Substan… = substância
Palavra que significa substância.
O que é substância?
Aquilo que algo é.
Ex.: homem, raio, céu, Jesus, Deus.
Como saber se uma palavra é um substantivo?
Aceita ser acompanhada por um artigo ou pronome? Ex.: o/a, um/uma, este/esta, meu/minha).


2. Substantivos próprios x comuns

2.1 Próprios: significam seres únicos, específicos, individuais. Grafados em letra maiúscula.
Exemplo:
Maria, Mariana, Eloá, Michaela, Sofia, Jesus, Tietê, Brasil.

2.2 Comuns: significam generalizações, conceitos. Grafados em letra minúscula.
Exemplo:
menina, rei, rio, país.

3. Substantivos concretos x abstratos

3.1 Concretos: Existem por si mesmos, não dependem de outro ser para subsistirem.
Exemplo: homem, cadeira, Deus, água, vento.

3.2 Abstratos: Dependem de outro ser para existir.
Exemplo: fome, beleza, coragem, saudade.

Aula 7 - Substantivos IV

Objetivos
Substantivos biformes;
Substantivos uniformes:
Comuns de dois gêneros;
Sobrecomuns;
Epicenos.

Gênero dos substantivos



1. Substantivos biformes
Biformes = bi (duas) + formes (formas)
Uma forma para cada gênero: uma para o masculino e outra para o feminino.
menino/menina
gato/gata
professor/professora
2. Substantivos uniformes
Uni- (uma) + formes (formas) = substantivos com uma forma só para os dois gêneros (masculino e feminino).

2.1 Comuns de dois gêneros
Substantivos fixos. A distinção de gênero é feita apenas pelo artigo/adjetivo.
o estudante / a estudante
o cliente / a cliente
o artista / a artista
o atleta / a atleta
Todos os substantivos ou adjetivos substantivados terminados em -ista são comuns de dois gêneros: pianista.

2.2 Sobrecomuns
Substantivos de gênero fixo. O artigo nunca muda.
A criança;
A vítima;
A testemunha;
O indivíduo;
O cônjuge.


2.3 Epicenos
Substantivos de gênero fixo relativos a animais. A distinção entre macho e fêmea é feita pelo acréscimo dessas palavras.
A cobra macho / A cobra fêmea;
O besouro macho / O besouro fêmea;
A borboleta macho / A borboleta fêmea.

Formação do plural: 
Regra geral
Regras especiais

Substantivos terminados em consoante
Alguns casos

1. Flexão de número
Substantivos podem estar:
No singular: aluno, cão, mesa, povo, manada.
No plural: alunos, cães, mesas, povos, manadas.

Formação do plural

Substantivos terminados em vogal ou ditongo → acrescenta-se -s.
Mesas, estantes, pais

Bem → Bens | Flautim → Flautins

Terminação -ão
1) -ões
balão → balões

2) -ães

2. Artigos

Definidos: tratam de um ser já conhecido pelo ouvinte.
“Atravessaram o pátio, deixaram na escuridão o chiqueiro e o curral, vazios, de porteiras abertas, o carro de bois que apodrecia, os juazeiros” (Graciliano Ramos)

Indefinidos: tratam de um simples representante de uma espécie a que não se fez menção anteriormente.
“Atravessaram um pátio, deixaram numa escuridão um chiqueiro e um curral, vazios, de porteiras abertas, um carro de bois que apodrecia, uns juazeiros”




3. Formas combinadas do artigo definido

Preposições      | artigos
a	        +    a        = à
de	        +    a        = da
em	        +    a        = na
por(per)  +    a        = pela

4. Crase

Crase é um fenômeno de fusão: preposição “a” + artigo “a” = à.
O fenômeno da crase é marcado com o acento grave: à.
Para ajudar a identificar quando ocorre crase: substituir por “para a”.
Exemplos:
Vou à praia = Vou para a praia.
Deu um presente à avó = Deu um presente para a avó.
Disse uma coisa à pessoa = Disse uma coisa para a pessoa.

Aula 12 - Adjetivo II

Objetivo
Flexão de gênero dos adjetivos;
Flexão de número dos adjetivos;
Substantivação dos adjetivos.

1. Flexão de gênero dos adjetivos
Seguem o gênero dos substantivos.


2. Flexão de número dos adjetivos
Simples e compostos.
Simples
Adjetivos com um radical só.
Seguem as mesmas regras do substantivos.
Compostos
Regra geral: apenas o último elemento recebe forma de plural.
Consultório médico-cirúrgico
Consultórios médico-cirúrgicos
Instituto afro-asiático
Institutos afro-asiáticos
Exceção: surdo-mudo → surdos-mudos

3. Substantivação dos adjetivos

O [céu] cinzento indicava chuva.
O [cinzento] do céu indicava chuva.

[Substantivo] [Adjetivo] → [Verbo] → [Complemento]

Tenho medo de lugar escuro.
Tenho medo do escuro.

Substantivação do adjetivo → Determinação via artigo, pronome ou adjetivo.
Escuro (adj.) ≠ O escuro (subst.)
Cinzento (adj.) ≠ O cinzento (subst.)
